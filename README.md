# Algorithms

Учебный репозиторий с реализациями алгоритмов на TypeScript. Решения задач по плану «Грокаем алгоритмы» + LeetCode.

План занятий и список задач: [algorithms-plan-grokking-leetcode.md](algorithms-plan-grokking-leetcode.md).

## Структура

- `1_level/` — базовые темы (массивы, строки и т.д.)
- `bynary/` — бинарный поиск
- `devide_concuer/` — divide & conquer (сортировки, k-й элемент)
- `linked/` — связные списки
- `recursion/` — рекурсия
- `strings/` — строки

Каждый файл — самостоятельное решение одной задачи на TS.
