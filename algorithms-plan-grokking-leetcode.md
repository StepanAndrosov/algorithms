# План изучения алгоритмов: «Грокаем» + LeetCode

**Как пользоваться этим планом**

- Структура — по модулям, а не по неделям: один модуль = одна тема, идём строго от простого к сложному. Внутри модуля: (1) если есть глава «Грокаем» — прочитать → (2) реализовать разобранный алгоритм с нуля на TS, без подглядывания → (3) решить задачи модуля на LeetCode → (4) раз в 1–2 недели вернуться к задачам прошлых модулей и решить 1–2 «вслепую».
- Таймбокс: залип на 20–25 минут — смотри решение/подсказку, разбирай, помечай что упустил, идёшь дальше. Не сиди часами.
- Темп: 2 часа в день ≈ 1 сессия. В сессию помещается разбор теории модуля (если она новая) + 3–6 задач в зависимости от сложности.
- Пиши всё на TypeScript.
- Codewars — опционально, разминка 1–2 каты 7–6 kyu в начале сессии.
- Если у задачи на LeetCode замок (premium) — берём бесплатный аналог (см. модуль «Интервалы»).
- `[*]` — уже решено, `[ ]` — предстоит.

# Уровень 4 — из вашего списка (отсортировано по сложности)

Вы дали 4 темы одним уровнем: backtracking, DP, жадные, сортировка. Внутри уровня выстроил по возрастанию сложности:

1. **Сортировка** — реализация известных алгоритмов, самая механическая тема, новой парадигмы решения задач не требует.
2. **Backtracking** — систематический перебор через рекурсию, прямое продолжение модулей «Recursion» / «DFS».
3. **Жадные алгоритмы** — требуют доказывать, что локально оптимальный выбор даёт глобальный оптимум; работает не всегда, из-за чего интуиция нарабатывается дольше, чем в backtracking.
4. **Динамическое программирование** — самая сложная тема: нужно распознать перекрывающиеся подзадачи и оптимальную подструктуру, часто уже после того, как не сработал жадный подход.
